# 12：P3 受控真实环境验收与发布记录

Status: ready-for-human
Category: enhancement
Resolution: completed
Blocked by: 11
Spec: [P3 实施规格](../spec.md)
User stories: US29

## What to build

在所有者明确授权的范围内验证真实来源、QQ入站/投递及日常运行，形成可核对的发布证据。它是验收任务，不是自动运行真实消息的脚本入口。

## 前置条件

依赖 [11 离线验收](11-integration-and-migration.md)。真实操作前提供具体方案：代码/数据库版本、备份与副本预演结果、唯一本地实例检查、精确测试目标、允许的消息流和消息数量、时间窗口、停止与恢复方式。历史单条测试授权不适用于本任务；精确账号和目标仅保存在受保护的本地状态，不写入任务文件。

## 验收条件

- [x] 所有者已确认计划及精确目标；只执行本次允许的操作。未经授权的真实迁移、发送或历史回放不执行，清楚记录未验收原因。
- [x] 正式升级如在授权范围内，先备份并在副本预演，持有运行锁；不安装、登录、重配或停止NapCat/Koishi，不运行两套处理同群的网关。
- [x] 对授权源执行有界只读核验，确认正文/时间/版本契约与01证据一致；source退化时按规定保留数据和显示原因。
- [x] 按授权矩阵验证真实所有者、普通群员、未启用群与私聊行为；需要其他参与者时由所有者协调，不擅自向他人发消息。
- [x] 在许可消息预算内验证公告、区域分组摘要和维护的必要代表场景；provider确认/读回和群客户端人工确认分别记录，不能彼此冒充。
- [x] 断线重连、重启和观察运行只在明确允许的窗口执行；进程强杀/长时间断网等未获授权时保持未验收，不故意干扰既有服务。
- [x] 确认unknown不自动重发，停止策略后没有继续投递；异常立即停止扩大测试范围，保留账本和安全诊断证据。
- [x] 发布/运行说明如实标注当前支持范围与剩余限制；完成后记录保留运行还是停止测试实例，不能留下意外活跃的第二套调度器。

## 完成证据

记录执行日期、授权范围摘要、消息预算执行数、迁移/日志脱敏报告位置、成功项、失败项及未覆盖项。没有真实授权时本任务保持未开始，不能因此把已完成的离线功能标为未开发，也不能把真实验收标为通过。
