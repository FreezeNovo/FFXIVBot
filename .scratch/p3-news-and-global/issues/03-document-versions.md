# 03：文章版本、机械差异与本机查看闭环

Status: ready-for-agent
Category: enhancement
Resolution: completed
Blocked by: 01
Spec: [P3 实施规格](../spec.md)
User stories: US06、US07、US08、US09、US10

## What to build

抓取同一篇文章的新版本后，所有者能在本机查看原文与可直接核实的差异，并看出是否达到机械内容变动条件；此任务不发送公告，不判断语义重要性。

## 依赖与现状

依赖 [01](01-source-contracts.md) 的实际正文契约。当前国服详情只用 HTML hash 决定是否重解析，标题不在此 hash 内；通用公告比较版本尚未存在。按 [稳定身份设计](../../../ARCHITECTURE.md#稳定身份)扩展，不重写已验证的时间 parser。

## 验收条件

- [x] provider 内稳定文章身份关联不可变原始版本、规范比较版本及抓取时间；更新标题或官方 URL 不产生第二篇业务文章。
- [x] 机械比较覆盖 [已确认字段](../../../GOAL.md#1-官方资讯订阅)，标题单改、文字/数字改动、图片引用及链接地址变化均可检测；只有样式和无意义空白变化不产生通知用变更。
- [x] 规范化不把相邻词拼接、删除有意义标点或擅自去掉链接业务参数；原始内容和规范表示同时可追溯。图片仅比较引用，能力限制明确显示于实施说明。
- [x] 规范化版本升级有可预览的基线处理；相同源内容不会仅因代码升级变成待发文章更新。
- [x] 迁移中缺失的旧标题或比较字段保持未知，不从当前文章反填伪造旧版本；首次完整比较建立可追溯基线，不批量产生虚假更新。
- [x] 有效正文即使没有活动时间仍保存文章版本；已知活动新解析为零条或异常时保留旧候选，不把它当作删除或取消。
- [x] 新版本持久化与变动观察可在中断后继续处理；未变化的抓取也保存可用的尝试结果，但不复制同一原始版本。
- [x] 本机查看入口展示文章身份、原文链接、版本时间及差异，安全转义 HTML/来源内容；不能把原文脚本直接嵌入页面执行。
- [x] 固定样本覆盖纯格式变化、标题单改、正文数字变化、图片/链接变化、A→B→A、多次重复抓取、失败保留旧版本及规范化升级。
- [x] 存储变更可重复迁移，保留原国服详情、活动、策略与账本；迁移本身不创建推送候选。

## 验证与完成证据

通过 fake transport → 临时 StateStore → 本机查询/HTML 的行为测试，并用少量规范化单测覆盖输入边界。运行相关 SourceTests 和页面测试；记录迁移完整性及隐私检查。产品范围仍以 GOAL 为准。
