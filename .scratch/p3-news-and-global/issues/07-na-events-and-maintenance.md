# 07：NA 正文、活动时间与独立维护流

Status: ready-for-agent
Category: enhancement
Resolution: completed
Blocked by: 04
Spec: [P3 实施规格](../spec.md)
User stories: US03、US06、US16、US17、US25

## What to build

从NA官方发现条目取得正文，保存可解释时间证据，群员可查询NA活动/维护并收到相应通知；所有者能在本机查看原文、版本和时间解释。保留已有国服行为。

## 依赖与现状

依赖 [04](04-immediate-announcements.md) 的公告通知链，其前置[03](03-document-versions.md)和[01](01-source-contracts.md)已提供版本能力与实际NA契约样本。当前只有NA Atom元数据发现，没有正文时间解析，维护的部分显示和来源健康检查仍固定为国服。

## 验收条件

- [x] 根据经核验入口抓取正文并接入版本/机械差异流程；列表schema异常、正文缺失、请求失败分别退化，不覆盖最后有效内容。
- [x] 只从明确正文证据提取活动或维护时间，保存原文证据、来源时区、换算假设、UTC、精度和parser版本；发布时间不充当活动开始时间。
- [x] fixture覆盖跨年、跨月、一文多活动、无时间、仅日期、明确时区、夏令时边界及schema变化；无法消歧时保留文章并标记不具备精确提醒资格，不伪造小时。
- [x] 时间解析成功可产生零到多条断言；已知活动重新解析为零或退化保留最后有效候选，不推断取消。无活动时间的普通文章仍可走公告流。
- [x] 保留官方原文标题，渲染中文分类标签、区域与北京时间；本机显示原文链接和证据，未引入标题翻译或中文摘要。
- [x] NA普通公告通过04的独立流程；NA维护通过已有维护规划/renderer/账本，默认提前量、公告/更新开关、未知结果语义不另建一套。
- [x] 移除维护流程中的国服显示与来源检查假设；改起止时间替换未发送提醒，parser升级但时间未改不重复通知。
- [x] 来源和区域身份稳定；不自动合并独立调整公告，不以URL或标题替换业务主键。国服现有fixture与维护回归继续通过。
- [x] 在单区域NA策略下从固定原始正文到本机查看、手动查询和fake主动消息完成端到端演示；多区域组合由09/11收口。

## 验证与完成证据

复用SourceTests、CalendarWorkflowTests、MaintenanceWorkflowTests及权限用例；单测不联网。记录parser契约、失败保留快照和NA渲染输出证据，更新DATA-SOURCES与当前WebUI支持范围，不能用NA代表其他国际服区域。
