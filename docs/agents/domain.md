# Domain Docs

本仓库采用 single-context 布局，路径相对于仓库根目录：

- `GLOSSARY.md`：统一领域术语。
- `docs/adr/`：按编号保存决策背景、取舍和历史。

## 阅读规则

探索代码前，先读已有的 `GLOSSARY.md`，
再读 `docs/adr/` 中与当前任务相关的记录。

文件尚不存在时继续工作，无需提醒或预先创建空文件。
领域建模过程中确有术语或决策需要记录时再创建。

## 使用术语

任务标题、设计建议、诊断假设和测试命名使用词汇表中的术语。
遇到未收录概念时，先核查代码和现有文档；
确有缺口再记录到领域建模工作中。

## 文档职责与冲突

权威信息分工遵循 [AGENTS.md](../../AGENTS.md)：
当前产品决定归属 GOAL.md，当前架构设计归属 ARCHITECTURE.md，
实现状态归属 TODO.md。

词汇表负责定义术语；ADR 保存背景、取舍与历史，
并引用对应权威文档，避免重复维护当前规则。

提议与已有 ADR 冲突时，明确指出记录编号、冲突点及重议理由，
再按项目的冲突处理规则推进。
